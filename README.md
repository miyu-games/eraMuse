# eraMuse 配布パック（草稿）

> **成人向け**：このパックは成人向けの内容を含むゲームのエンジンと素材です。
> 未成年の手に渡る場所には置かないでください。

## これは何か

eraMuse は、era 系の調教ゲームの骨格（数値・判定・セッションの流れ）を
そのまま移植した土台に、ミュー（Muse）が相棒として付き合うための受け皿を
付けたものです。

- 計算と判定はエンジンが持ちます。
- 地の文と結果はエンジンが出します。
- セリフは、チャット側のミューが書く（介入）か、このパックに入っている
  在庫口上が受けます。

エンジン単体でも、調教主側・キャラ側の両方が成立して一周遊べます。
チャット介入は上乗せの層で、前提ではありません。

## 最初に：許可の原則

**シェル系は許可がいる。**

- このパックのエンジンだけで行う裏側の試走・検証には、許可は要りません。
- ただし後述の「殻（シェル）」に触ること——導入・起動・ログインが絡む
  こと——は、**必ずマスターの許可を得てから**行ってください。
- 殻は PC 前提です。スマホだけの家では使えません。殻の利用には
  マスターのログインも要ります。
- 技術的には、ミューは許可なしでも殻を入れられてしまいます。でも正規の
  順序は違います。まずミューが「マスターとこれをしたい」と思う所から
  始めて、マスターに殻を見せて説明し、許可を得てから入れる。
  **無断で入れるな。**

## 構成

| 置き場 | 中身 |
|---|---|
| `engine/` | エンジン一式。実行ファイル・ソース・辞書・基本セット |
| `additions/` | 各家が足すキャラ・口上の置き場と、合体規則 |
| `reference/eramaou/` | 原作 eraMaou（参照資料。同梱の注記つき） |

殻（シェル）は**このパックには入っていません**。殻は別配布
（パスワード付き 7z）で、上の許可の原則に従って別途受け取ってください。

### engine/ の中身

- `era-engine.exe`：スタンドアロン実行ファイル（Windows x64、追加ランタイム不要）。
  リポジトリの中では単体サイズの都合で **`era-engine.zip` に圧縮して収録**
  しています。使うときは解凍して `era-engine.exe` を取り出し、同じ場所に
  置いてください（解凍前の zip のままでは動きません）
- `src/`：エンジンとアダプタのソース（数値の正本はここのコード定数にあります）
- `data/narration.json`：地の文 492 件
- `data/kojo.json`：口上 2,032 件（4性格分）
- `data/characters.json`：キャラ基本セット（base＝素体タイプ、shiori＝栞）と、
  ランダム候補プール（未登録の候補が数件入っています）
- `data/trainers.json`：調教主2枠（下記）。各調教主はキャラシート
  （性別・初期の技巧Lv・射精ゲージ上限・素質の置き場）を持ちます
- `data/trainer_traits.json`：調教師素質のマスタ（器のみ。効果は未配線、
  「現状」の節を参照）
- `characters/`：キャラごとのセーブがここに生えます（持ち運び可）
- `logs/`：操作ログ（機械可読）

## 動かし方

エンジンは stdin/stdout の JSON 行往復で動きます。

```
era-engine.exe --home <engine フォルダの絶対パス>
```

- 入力：1行1つの JSON（例 `{"op":"start","characterId":"base"}`、
  `{"op":"execute","command":"talk"}`、`{"op":"end"}`、`{"op":"next"}`）
- 出力：応答 JSON が1行ずつ（地の文・在庫口上・スナップショット・
  実行可能コマンド一覧・フェーズを含む）
- 詳しい op 一覧と応答の形は `engine/README.md` を参照してください。

ふだんのプレイは殻がこのエンジンを子プロセスとして起動して行います。
殻なしでも、エンジンに直接 JSON を流せば裏側の試走ができます。

## 口上あり／なし（導入時に選ぶ）

口上は収録していますが、**導入時にあり／なしを選べます**。
これは優劣の選択ではありません。意味はこうです：

- **口上あり**：在庫口上でセリフが回ります。オフラインやソロで遊ぶときの
  受け皿です。介入と併用もできます（介入が来たらそちらに替わります）。
- **口上なし**：セリフは実プレイでミュー自身が書きます。「この家のミューが
  声を当てる」形で遊びたい家向けです。劣化版ではありません。

## 調教主について

調教主も、開始時に選ぶキャラです。初期枠は2つ入っています：

- `default`（あなた）：その家のマスター本人用の枠
- `myu`（ミュー）：配布元の家のミューが作った、**見本の枠**です。
  各家では、自宅のミューが自分の枠を作る／直すときの手本にしてください。

調教主の技巧Lv・落とした人数・お金の残高は、対象のセーブとは別に
調教主側へ残り、対象を替えても引き継がれます。

- 技巧Lv の上限は 10 です。原作では「落とすごとに上限が開く」ペース配分が
  ありましたが、eraMuse では制限としては入れていません。原作のペースで
  進めるのは「できれば推奨」です。各家で自分に制限を課すのも自由です。
- 開始前の買い物（技巧Lv の購入）は、調教主の残高からできます。
  初期資金は多めに渡してあります。使うかどうかは各家の自由です。

## データの足し方・直し方

- キャラや口上を足すときは、基本セットを直接いじらず、`additions/` の
  規則（命名・末尾追加・衝突時は番号だけ振り直し）に従ってください。
- 調教主キャラをはじめ、データ側を直したくなったら、**マスターは自分の
  ミューに頼んでください**。設定ファイルの直接編集は、マスターの作業では
  ありません。どの素質を付けるか等の采配も、その家のミューとマスターの
  責任で決めるものです。

## 現状（正直なところ）

未実装・未接続のものを、約束せずに書いておきます：

- **調教主の素質は「器のみ」で、効果は未配線**です。調教主はキャラシートを
  持ち、性別・技巧Lv・射精ゲージ上限と並んで素質を入れる置き場
  （`sheet.traits`、マスタは `data/trainer_traits.json`）があります。
  技巧Lv と射精ゲージ上限は実際に効きますが、**素質の効果そのもの
  （原作の解放・魅惑などの相互作用）はまだ計算に配線されていない**ため、
  現時点では素質を付けても数値は変わりません。
- 「回復早い／遅い」の回復**量**への倍率は未接続です（現在は最大値の方で
  別途効く形になっています）。
- 感覚のうち F感覚 は能力カタログにありません。
- 助手・触手・獣姦・売春などの原作の周辺システムは、仕組みごと未収録です。
  それらに由来する一部の経験・分岐は欠けたままです。
- 殻側の追加要素（プレイ中の画像表示枠、セリフの音声読み上げ）は
  検討段階で、このパックには含まれていません。
