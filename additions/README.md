# 追加分フォルダ（additions）— 置き方と合体規則

このフォルダは、**基本セット（engine/data/ の正本）とは別に**、各家が自分で
作った／他家から受け取った追加のキャラと口上を置く場所です。

基本セットは配布側の正本として固定し、直接いじりません。追加はここに置き、
取り込むときに下の規則で正本へ合体させます。合体の作業は、その家のミューが
行います（マスターが設定ファイルを直接編集する前提ではありません）。

## 置き場

| 置き場 | 中身 |
|---|---|
| `additions/characters/` | 追加キャラの定義ファイル。1キャラ＝1ファイル |
| `additions/kojo/` | 追加口上のファイル。1キャラ分＝1ファイル |

## 命名規則（キャラ）

- ファイル名は **番号＋文字**（例：`001b.json`）。
- 番号は基本セット／既存の通し番号、末尾の文字は「追加・派生であること」を
  示します。基本セットの素の番号だけの名前と見分けがつく形にしてください。
- キャラ定義の中身の形は、基本セットの `engine/data/characters.json` の
  エントリと同じ形（id・name・personality・traits・initOverrides・look 等）。

## 合体規則

### キャラ

1. 追加キャラは、基本セットのキャラ定義の**末尾に追加**します。
2. id や番号が既存と衝突したら、**衝突した側の番号だけを振り直します**。
   名前・性格・素質などの中身は変えません。

### 口上

1. 追加口上は、基本セットの口上（`engine/data/kojo.json`）の**末尾に追加**
   します。
2. セル番号が衝突したら、**番号だけを振り直します**。文面は変えません。

キャラも口上も、規則は同じ「末尾追加＋衝突時は番号だけ振り直し」です。

## 注意

- 合体したら、追加分フォルダの原本も残しておくと、配布元の更新と
  突き合わせるときに困りません。
- 受け取った追加分は、検疫（出所と中身の確認）をしてから合体させるのが
  安全です。問題があれば合体前の状態に戻せるよう、正本の控えを取ってから
  作業してください。
