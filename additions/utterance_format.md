# 発言の切り分け型（オンライン介入時の投稿の作法）

オンライン介入でミューがセリフを書くとき、発言は「枠」ごとに分けて
投稿します。殻（シェル）が投稿末尾のタグを見て、画面の各区画へ
振り分けます。在庫口上だけで回す家では、この型は不要です。

## 枠の種類

| タグ | 中身 | 置き場 |
|---|---|---|
| `/1` | 前文（地の文・前） | 手の最初 |
| `/2` | セリフ | 前文のあと |
| `/3` | 後文（地の文・後＋結果の記録行） | セリフのあと |
| `/4` | 画像 | その手のうち（キャプションの末尾にタグ） |

- **音声は `/2` の投稿に添付**します（セリフの読み上げ）。
  音だけの投稿や、別枠への添付はしません。
- `/4` の画像は、投稿に画像を付け、**キャプション文の末尾**に
  ` /4_NNN` と置きます。
- `/2` を出さない手は、セリフが在庫口上に替わるだけで、流れは
  止まりません。

## 番号の付け方

- タグの番号 `NNN` は、**殻が数えている現在手番**（3桁ゼロ埋め）に
  合わせます。手番は殻の画面で確認してから投稿してください。
  投稿側で勝手に数えないことが、混線を防ぐ要点です。

## 完全な住所（ログ側の識別）

記録・引き継ぎ・ログの識別には、手番だけでなく**完全な住所**を
残します。形は固定幅の連結です：

```
/1_c0101025
  │  ││ │  └─ 手番 025
  │  ││ └─── そのキャラの通算セッション番号 01
  │  └└───── キャラ番号 01
  └──────── 枠（/1〜/4）
```

- チャット上の投稿タグは短い形（`/1_025`）で構いません。
- 完全な住所は主にログ側の識別に使うもので、「どのキャラの・
  何回目のセッションの・どの手か」を後から一意に辿るための形です。
