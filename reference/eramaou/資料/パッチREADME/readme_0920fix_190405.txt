■CAMPAIGN_EVENT.ERB
・キャンペーン終了時、PTを結成している場合に解散がされないのを(多分)修正
@CAMPAIGN_ENDING で @PARTY_DEL, ARG:0 だと最深階層に到達したPTのみが対象のようなので
敵地派遣中フラグが立っているキャラ全部に解散処理を実行
これだとキャンペーン終了時に未行動のキャラがダンジョン探索を行ってしまうので、敵地派遣中フラグも初期化
@CAMPAIGN_GAMEOVER では敵地派遣中フラグの初期化のみ行っているようなので解散処理を同様に追加
適切な方法があったら誰か修正して欲しい
・キャンペーン終了時、参加者の帰還中フラグも初期化
