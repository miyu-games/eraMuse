**Gスポ/子宮口の A 式**（COMF20/21/22/23/34 共通、実測）:
A = 欲情帯 × RAND:11 + RAND:11 × V感覚（ABL:2）。欲情帯は PALAM:5 を PALAMLV（100/500/3000/10000、『_replace.csv』の初期値列）で帯化した 1〜5。A が基礎ごとの閾値（正常位40・後背位50・対面座位30・背面座位60・騎乗位50）以上なら子宮口、未満なら Gスポ。試作での PALAM:5 の置き場は `desireSession`（UP:5 のセッション蓄積、PALAM スケール——精算用に既存の写像）。RAND はエンジン共通の `roll()` から RAND:11 として引く。

**派生先 ABLE の固有分**（COMABLE 実測）:
- 120/121: 正常位の ABLE と実質同等（バイブ挿入中不可・対象オトコ不可・調教者の装備・お風呂場マット）。試作では sex_v の unlock と同形の式で評価。
- 123: 従順(10)・技巧(12)・奉仕技術(13) のいずれか ≥3。124/126/127: 従順・技巧・奉仕精神(16) のいずれか ≥3。125: 123 と同型。共通で縄(44)・ボールギャグ(45) 装備中は不可。試作の能力には奉仕技術の独立枠が無いため、既存 unlock と同じく abl_service へ寄せて `(abl_obedience >= 3 || abl_skill >= 3 || abl_service >= 3) && tequip_44 == 0 && tequip_45 == 0` で評価。
- 128/129/131/132: 調教者技巧 ≥3（または 性交技術 ABL:14 ≥2 の代替路——試作に能力が無いため欠け）。130/134: 技巧 ≥5（代替路 ABL:14 ≥3 も欠け）。133: 技巧 ≥4（同）。共通の性交系ゲート（tool_v・対象性別・装備・マット）は sex_v と同形で含めた。

## 2. 実装の形

- `resolveDerivation(s, baseId)`（engine.ts、export）: 手の開始時点の状態だけで派生を評価する純粋な解決段。§1 の表そのまま。
- `executeCommand` の組み込み位置: 基礎コマンドの unlock・疲労チェックの後、**実行判定（ORDER_JUDGES）の前**（原作で JUMP が @COMF 冒頭にある位置）。派生が決まれば、以後の全て（実行判定・ソース・部位テーブル・コスト・射精・経験・地の文/口上セル・usedCommands・prev/prevPrev の記録）は**派生先コマンドの定義で**処理される。基礎コマンドの数値で代用する箇所は無い。
- 応答への明示: `ExecuteResult` に `commandId`（実行された側）・`commandLabel`・`derivedFrom`（基礎側ID、派生なしは null）を追加。後文（narration3）の先頭に `（派生）基礎名 → 派生先名` の記録行が入る。cli のオペレーションログにも `executedCommandId` / `derivedFrom` を記録。
- 一覧表示は従来どおりマスクのまま（複合は選ぶものではない）。複合IDの直接実行は従来どおり弾かれる。
- 殻（MainForm.cs）: 応答フィールドの追加のみで、表示は narration3 の記録行で追随するため**変更なし**。

## 3. 一致 / 欠け / 余計

**一致**（原作形どおりに動く）:
- §1 の派生条件・判定順（SP を Gスポ/子宮口より先に評価、フェラチオ内の判定順）・A 式と基礎別閾値・ABLE 不成立時は基礎が通常実行・ランダム分岐で選ばれなかった側を試さない点。
- 派生した手の履歴記録は派生先（PREVCOM/TFLAG:59 相当が派生先で回るため、128→129→正常位→SP のような連続条件が原作どおり成立する）。
- 派生先のソース・部位テーブル・射精 B・経験・口上/地の文セルは派生先の定義そのまま。

**欠け**（前提システムが試作に無く、無理に作らなかった物）:
- **セルフクンニ（com135）**: 派生ではなく種族前提（TALENT:314 デュラハン）のコマンド。前提データが無いためマスク据え置き。
- フェラチオ→**シックスナイン（COM69）**（前回がクンニ/フェラする/69）: カタログに COM69 自体が無いため未接続。
- **3P（COM64）への派生**（前回 3P / 調教者交代時）: 助手システムが無いため対象外。
- ABLE の落とした項: FLAG:71（追加コマンド許可設定）・未熟 TALENT:135＋調教者サド・貞操封印 TALENT:273・着衣条件・性交技術 ABL:14 の代替路・パイズリフェラの胸サイズ素質（TALENT:109/110/114/116/119）。いずれも対応する素質・能力・システムが試作に無い（基礎コマンド側の従来扱いと同一）。
- フェラ系 ABLE の調教者性別ゲート（TALENT:PLAYER:121/122、PBAND 代替なし）: 基礎コマンド側の判断（女性調教師でも実行可として付けない・判断待ち）に合わせて付けていない。

**余計**: なし（新規の条件・数値は作っていない。DERIVE_ABLE は全て COMABLE 実測の写像）。
