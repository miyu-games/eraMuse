## 詰まり・違和感（「進む／進まない」の観点）

1. **欲情・屈服の珠がほぼ死んでいる。** 両者はパラメータ（欲望・屈服）のセッション増加分からのみ精算されるが、パラメータは上限1000・減少なしのため、生涯収入は各 10〜20 個程度。両ランとも最終所持 0〜9 で推移した。影響: 欲望ABL は Lv2（欲情の珠50）以降ほぼ到達不能（Lv3 は条件の一つが欲望 3 のため淫乱側が二重に詰む）、奉仕・従順の屈服ルート、反発消去（5000）がすべて閉じる。原作はパラメータではなく PALAM のセッション増加分が珠になるため、パラメータ・キャップ写像との相性問題と見られる（推測：原作形では毎セッション増分が再計上される）。
2. **淫乱ルートは到達不能（実装上の上限）。** 異常経験の発生源が全エンジンで2つだけ（撮影中自慰の初回 +1、強制精飲の初回 +1）で最大 2 ＜ 条件 3。原作ではフィスト・浣腸・放尿等の行為→経験対応表から入る分が未接続。欲望ABL の異常ゲート（Lv7→8 に 3）も同じ理由で閉じている。
3. **疲労の壁がペースを決める。** 疲労100で休憩以外全コマンド拒否、回復は休憩（−32）と日跨ぎ（−45）のみ。重いコマンド（疲労源150級）は実質 6〜7 手/日が上限。序盤に重い手を連打した試行では午前 3〜4 手・午後 0 手まで落ちた。軽い手（贈り物＝疲労1/手）中心なら 130 手/セッション回るため、セッションの「長さ」はコマンド選択で 30 倍以上変わる。
4. **序盤の正否判定（実行値）の壁は実在するが越えられる。** 奉仕系の主力 com123 が従順 3 でも素では 1 点差で落ちる。帯（同セッションのソース蓄積）が上がる後半に通る設計なので、「判定で落ちたら別の手で帯を積む」が常識的な解になる。判定不成立はノーコストなので試行自体は無料。

## バグ・要確認

### 絶頂した手で苦痛刻印と反発刻印が立つ（再現あり）

- 再現: ラン1、Day 7 午前、従順ABL 3・奉仕ABL 0 の状態で com123 を反復し、B のセッション蓄積が 10000 を超えた手（初の B 絶頂）で「苦痛刻印LV2を取得」「反発刻印LV1を取得」が同時発生した。com123 自体に苦痛ソースはない。
- 原因: 絶頂波及テーブル `CLIMAX_WAVE`（engine.ts）が絶頂部位ごとに苦痛チャンネルへ C/B=150、V=300、A/F=400（×強度）を加算し、その値が刻印判定（@MARK_GOT_CHECK 写像）の苦痛UP・反感UP の両方に流れるため。従順 3 では B 絶頂1回で苦痛UP 1500（刻印LV2 ちょうど）と反感UP 600+不潔分（反発LV1）に達する。従順が低いほど反感倍率が上がり、従順 0 の C/B 絶頂では反発LV2 になる計算。
- 判定: 原作の絶頂時 PALAM 増加（反感等）を試作ソースへ写像した際の副作用と見られる（推測：原作では絶頂の反感は UP:11 へ直接入り、苦痛 UP:9 は上がらないため、苦痛刻印は立たないはず）。少なくとも「快楽行為の絶頂で苦痛刻印LV2」は体感として不自然で、陥落条件（反発 0）と正面衝突するため、実プレイでは絶頂回避が必須戦術になる現状は要確認と考える。
- 回避策（ラン2で実証）: 全部位のセッション蓄積を 10000 未満に管理すれば絶頂自体を起こさずに愛まで到達できる。快楽刻印 3 は絶頂ではなく単手 CUP 3000 で取れる。
