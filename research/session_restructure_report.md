## 変更点

### エンジン（engine/src/engine.ts）

1. **セッション形**：1日3行動の強制終了を廃止。1日 = 2セッション（午前 `slot=0`／午後 `slot=1`、原作 TIME の形）で、調教は調教終了（新 op `end`）までコマンド回数の上限なく続く。期間は 14日 = 28セッションと再定義。
2. **資源による区切り（原作 @SOURCE_CHECK の形）**：手開始時点で気力が 0 以下なら、体力消費が **×2 + 80**（気力消費は倍化しない）。同時に原作の半減対象 PALAM（恭順・欲情・苦痛）に対応するソース（affection / pleasure / pain）を半減（写像の範囲は後述の留保参照）。体力・気力はクランプを外しマイナスになりうる形に変更（従来は 0 クランプ）。
3. **倒れる処理（原作 @EVENTCOMEND → @EVENTEND の形）**：手の解決後に体力 ≤ 0 なら「彼女はぴくりとも動かなくなった」でセッション強制終了し、メニューへ移る。原作はキャラ削除＋珠なしだが、eraMuse では**キャラは残し、精算なし**にした（判断として明記。精算入力は破棄される：快部位残量とセッションEXは次セッション開始時に捨て、ウォーターマークは開始時点で置き直す）。
4. **精算タイミング**：珠換算（@JUEL_CHECK_MAIN 全体形の移植）を日次ロールオーバーから**調教終了時**へ移行。入力は日次増分から**セッション増分**へ（ウォーターマークはセッション開始時点で置き直す。原作は PALAM がセッション内累積で絶対値を読むため、実質は同じ入力）。精算ガードは日→セッション番号（`settledSessions`）。
5. **回復（原作 @EVENTTURNEND の形）**：セッション遷移時に、体力は 1 未満なら 1 へ引き上げたうえで、午前→午後は 最大/10、午後→翌日（夜）は 最大/2 を回復。気力は毎セッション全回復。射精ゲージはセッション開始で 0（@EVENTTRAIN の形）。疲労 -45・反発 -10 の緩和は日境界（午後→翌日）にのみ残した。
6. **購入はメニュー側**：旧「1日最終手→購入フェーズ（shop）」を廃止。調教終了後のメニュー（phase `menu`）でのみ購入可にし、調教中は不可のまま。期間終了後のメニューでも分岐選択前なら購入可（原作でも最終セッションの EVENTEND で JUEL_CHECK が回る位置）。
7. **期間終了・延長**：最終日の午後のメニューで「次へ進む」を選ぶと期間終了（finished）。延長（extend）は延長期間の初日・午前のセッション開始まで込みになった。
8. **日送り挨拶の口上**（greeting/day2plus）の受け皿は、手の選択肢から日が替わる遷移側へ移した（次セッション開始時に先行表示）。
9. **旧セーブ移行**（normalizeState）：phase `shop` → `menu` 読み替え、旧 `exToday` は `exSession` へ引き継ぎ、旧 `stressPosToday` は破棄して 0 から（日の途中の累積をセッション増分と読み替える根拠がないため）、slot/sessionSeq 等は既定値で補完。合成した旧形式セーブで移行→プレイ継続を確認済み。PC 側の実セーブは転送時に同じ経路で移行される。

### 解放条件（engine/src/gamedata.ts の unlock 欄のみ）

パック側の数値ゲート（信頼・欲望等の閾値）を全て外し、eraMaou COMABLE の状況条件へ置換した。

- 初期状態（現代セッション、表示82件）で**実行可 72件**。ロックされるのは COMABLE ゲート 9件＋記録連鎖 1件のみ：
  - 秘貝開帳：従順 ≥ 2 ／ 羞恥プレイ：従順 ≥ 2 ／ お風呂場プレイ：従順 ≥ 2 ／ ピアシング：従順 ≥ 3 ／ 野外プレイ：従順 ≥ 3 ／ 浣腸器＋プラグ：従順＋欲望 ≥ 10 ／ イラマチオ：従順＋欲望 ≥ 6 ／ 新妻プレイ：C感覚 ≥ 3 ／ 素股：潤滑 ≥ 2000
  - 記録を見せる：撮影記録の実行済み（従来の連鎖から数値部分だけを除いた形）
- 表現できず落とした条件（捏造していない）：V/A経験ゲート（COM22/23/26〜29/81/82/83 — 経験カウンタが無く、実行回数への読み替えは尺度が違うためしない）、調教者側の能力（COM44 縄）、装備状態（COM85 放尿）、アイテム所持（道具系全般 — 所持システムなし）、服装・汚れ・助手・失神・フィルタ起源の不可（対応システムなし）。詳細は実測メモ §3。
- gamedata の数値表（sources / partStages / costs 等）はパック正本のまま。unlock 欄だけが正本から意図的に乖離し、その旨をファイル先頭コメントと README に明記した。

- **能力表示シート（1枚目）を原作レイアウトに再構成**：縦に流れるテキスト＋点線区切りで、名前／体力・気力バー／素質を [ ] で折り返し列挙／能力は4列「名前 - NLV」／刻印は「名前：LVn [*..]」ドットゲージ／経験カウンタ（絶頂経験・射精回数・部位別絶頂）／珠は4列。その後段に eraMuse のパラメータと目標（従来シートから存置）。珠は現行エンジンの通貨（快楽の珠に統合済みの9種）のまま表示し、経済には触っていない。一人称の行は、キャラ定義に対応フィールドが無いため出していない（欠けとして区別）。
- **能力表示の巡回**：[100] を押すたびに 状態 → シート1枚目 → 状態 と巡回する形に変更（単純トグルではない）。原作の巡回先である2枚目（見た目プロフィール）は受け皿がないため巡回は2点になっている（欠け、後述）。
