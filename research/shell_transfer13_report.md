## 実装内容（`MainForm.cs` のみ）

### 1. 音声DOM採取（検証パネルの新ボタン「音声DOM採取」）

ウィジェット再生のボタン特定を実機ログからの推測で3回外した（転送⑩＝隣の投稿のボタン、⑪＝単位内の無関係ボタンで即決、⑫＝候補1件のみで全滅）ため、推測をやめて DOM の実形そのものを採取する診断を追加した。

- 検証パネルの「音声」行の下に「DOM採取」行を追加（パネル高さ 482→516）。ボタンは常時有効だが、追跡中の手（_trackSeq）が無い場合はその旨をログして何もしない。
- 新規スクリプト `JsDumpVoiceDom`：抽出と同じ `tightest()` で現在の手の ` /2_NNN` アンカーを特定し、以下を採取する。
  - **祖先チェーン**（最大10段）：各段の tag／class／rect、その段のサブツリーが含むタグ付き手番一覧（seqs。どの段から共有コンテナになるかが読める）、子要素の概要（tag と class の一覧）。
  - **投稿単位のサブツリー**：単位根は「別の手のタグを含む最初の祖先」の1つ下（無ければ A3）。単位内の全メディア要素（audio/video/source の src・currentSrc・source の type・paused/muted/dur/ct/ready）と全 button／[role=button]（aria-label・title・テキスト断片・内包 svg の有無と svg title・class・disabled・rect）を列挙。
  - **前後の兄弟サブツリー**：祖先 A0〜A3 の各段について前・次の兄弟を最大2 hop ずつ、同形式で列挙。
  - **文書順の近傍単位**：アンカーの直前・直後にあるメディア要素から2段上までを presentation らしい単位として列挙（単位根と同一なら省略）。
  - URL は形だけ（scheme＋パス／blob の長さ）に短縮し、署名付き URL 全文は残さない。行数は240行で打ち切り（打ち切り自体も明記）。
- C# 側ハンドラ `OnVoiceDomDumpClick`：要約行（祖先段数・ボタン件数・メディア件数＋保存先）を出し、全行を `DOM ` 接頭辞つきでパネルログに出力。全文は AppDir のテキストファイルにも保存する（`%LOCALAPPDATA%\EraShellSpike\voice_dom_<手番3桁>_<日時>.txt`）。採取は読み取りのみで、再生・送信には触れない。

### 2. 吸い出しフォールバックの正直化

- `JsPlayVoiceBlobFetch`：fetch した blob の `type`／`size` をステータスに記録するようにし、**type が判明していて audio でない場合は再生せず**、ステータスを `fetch='notaudio'`／`state='not-audio'` にして止める。type が空（判定材料なし）の場合は従来通り。`JsVoiceStatus` も blobType／blobSize を返すよう拡張。
- `PlayVoiceAsync`：ポーリングで `notaudio` を検出したら「ボイス: 吸い出したデータは音声ではありませんでした（type=…）。再生しません。」と記録して、その発火を終了する（残りの要素直接・URL 経路も同じ無音動画しか指さないため降下しない）。これまで波形動画（video/mp4）の fetch 成功が「自動再生しています」に化けていた経路を遮断した。
