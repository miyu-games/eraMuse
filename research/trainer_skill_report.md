## 実装した物

### 1. 全体倍率（一致）
`TECH_SOURCE_MULT = [0.50, 0.80, 1.00, 1.20, 1.50, 2.00]`（Lv0〜4、Lv5以上は末尾で頭打ち。原作は ELSE 段＝Lv5〜10 同値）。部位駆動値（partBases / partStages の drive＝原作 SOURCE:0/1/2/17 に対応）へ、潤滑倍率・自慰倍率と同じ段で掛ける。**快F（SOURCE:18）は原作でも対象外**なので techMultOf が 1 を返す。
- 帰結: 技巧Lv0 では全コマンドの快駆動が原作どおり半分になる。これが ITEM:52 を買う意味の本体。

### 2. 情愛・液体追加の梯子（一致、キスの既存配線を実測表へ置換）
共通の情愛梯子 `[100, 150, 200, 300, 500, 800]`:
- COMF6 キス: 代入（＝情愛の基礎値そのもの）
- COMF22/23/28/29: 加算
- 試作では従来のキス換算（基礎100を含む形）をそのまま流用し、増分 `[0, 5, 10, 20, 40, 70]`（＝(梯子−100)/10）を対象5コマンド共通で加える（`TECH_AFFECTION_ADD` / `TECH_AFFECTION_COMMANDS`）。

液体追加（SOURCE:10 → 潤滑発生へ合算）は梯子が2形ある:
- キス（COMF6）: `[0, 0, 0, 50, 100, 200]`
- 座位系（COMF22/23/28/29）: `[0, 50, 100, 150, 250, 400]`
- **修正点**: 従来の `KISS_TECH_LIQUID = [0, 50, 100, 150]`（Lv3頭打ち）は、キス梯子でも座位梯子でもない近似だったため廃止し、実測の2表（`TECH_LIQUID`）へ置換した。

### 3. 座位系の A 値（一致 ※SIF の定数評価まで含めて原作どおり）
4座位共通の A 梯子 `[0, 0, 0, 50, 100, 300]`（試作では駆動尺度 1/10 で `[0, 0, 0, 5, 10, 30]`）。A は快C へ常時加算され、主部位へは SIF つきで加算されるが、その SIF は **EXPLV が静的閾値配列（初期値 0/1/4/20/50/200/400/700/1000/1500/2000、書き込み箇所なし）のため定数評価になる**:

| コマンド | SIF（原文） | 定数評価 | 実効 |
|---|---|---|---|
| COMF22 対面座位 | `SIF EXPLV:0 >= 3` → 快V += A | 0 >= 3 = 偽 | 快C のみ |
| COMF23 背面座位 | `SIF EXPLV:10 >= 3` → 快V += A | 2000 >= 3 = 真 | 快C・快V |
| COMF28 対面座位アナル | （SIF 自体なし） | — | 快C のみ |
| COMF29 背面座位アナル | `SIF EXPLV:1 >= 3` → 快A += A | 1 >= 3 = 偽 | 快C のみ |

原文の意図は「対象部位の経験Lv≥3」だったとみられるが、字面の実効は上記のとおりで、そのまま写した（`TECH_A_PARTS`）。COMF120/121 だけは正しい形 `SIF EXP:0 >= EXPLV:3`（V経験 ≥ 20）で書かれている（ただし後述の 612 分岐内）。
- 実装方法: 駆動への加算として partStages / partBases の両ループへ畳み込み（原作では COMF 内加算 → 全体倍率、の順序を保存）。段階表・基礎値を持たない部位（com22 / com28 の快C）は A 単独の駆動として起こす。
- 写像上の近似（明記）: 段階表つき部位では A に感覚倍率が掛からない（段階表自体が感覚Lv別のため。A 単独駆動の部位には partBases 型チェーンで感覚倍率を掛けた）。原作では SOURCE 合計へ一律に感覚変換が掛かる。
- キス（COMF6）にも同じ A 梯子があるが、設定後にどこからも消費されない（死に値）ため接続していない。

### 4. 派生ゲート（一致）
- **COM120/121 の解放条件へ `trainer_skill >= 3` を追加**（gamedata の unlock）。原作では COMF20/21/22/23/34 の実行時に「前手が同系統 && 技巧 > 2」で派生抽選（欲情×V感覚で 120/121 を選択）する形だが、試作では 120/121 を独立コマンドとして置く既存設計（第2ラウンド項目D）のため、ゲート部分のみ原作形で接続した。派生抽選そのものは作っていない。
- COMABLE44 縄（技巧 ≥ 3）: 第2ラウンドで接続済み（再確認のみ）。
- COMABLE128〜134 の OR 条件（`技巧 < N && 対象の性交技術 ABL:14 < M` で不可）: 試作の能力カタログに性交技術が無いため、従来どおり PLAYER 側のみ接続（**欠け**: OR の対象側）。
